# BAS science & robotics lab (microgravity Panda workcell)

Generated by `build_bas_lab.py` (re-run it to regenerate every file here). The older table scenes
(`panda_pick_place_marker.xml`, `panda_station_marker.xml`) are unchanged and still work.

## Files
| file | what |
|---|---|
| `bas_lab.xml` | main scene (one cube + one target). Gravity 0, includes the modules below, keyframe `home` |
| `bas_lab_extra_objects.xml` | same plus a sample canister and a small box (`build_bas_lab.py --extra_objects`) |

## Coordinates
Origin = robot base. +x forward over the bench, +y left, +z = module "up". Bench top z = 0.375 m (same as the old table),
cube/marker ranges unchanged. Module axis = y through (x 0.55, z 0.85). Racks are visual only; bench, mounting rack and cube collide.

## Microgravity and the holding mechanism
`gravity = 0`. The bench top is a **velcro surface**: actuator `velcro_surface` (adhesion, 1.5 N) pulls anything touching it
onto the top; the keyframe sets its control to 1 (reset via `mj_resetDataKeyframe` keeps it on). The Panda grip (~3.7 N friction
capacity) pulls the cube off; a cube lifted off stays where released (no gravity). Cube/other objects have contact
`margin=gap=0.003` (needed for adhesion to engage) and a little joint damping (air drag). The velcro must stay weaker than the grip.
Velcro off: set `data.ctrl[8] = 0`.

## Adding things
* More objects/sensors/tasks: write a `mod_*.xml` with its own `<worldbody>/<asset>/<sensor>` and add an `<include .../>` line in `bas_lab.xml`
  (add its free-joint qpos values at the end of the keyframe `qpos`).
* A second arm (tested): attach with a prefix, e.g.
  `child = mujoco.MjSpec.from_file("arm_only.xml")` (an `<mujoco>` with `<compiler meshdir=...>` + `<include file="mod_panda_arm.xml"/>`),
  `frame = spec.worldbody.add_frame(pos=[...]); spec.attach(child, frame=frame, prefix="arm2_")`.
* Cameras are in `mod_cameras.xml`; render with `Renderer.update_scene(data, camera="bench_cam")`.
